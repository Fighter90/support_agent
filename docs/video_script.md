# Демонстрационное видео

Готовое видео: https://methodagent.ru/materials/demo.mp4 (2:43, субтитры в кадре и отдельным файлом `demo.srt`).

## Как оно соответствует требованиям организатора

- Продолжительность — до 3 минут.
- Один дубль без монтажа. Ускорено только ожидание ответа модели; в кадре в это время написано «ожидание ответа модели — в ролике ускорено».
- Работает настоящий стенд methodagent.ru на данных задачи: живой фид, база знаний, GigaChat 2 Max, настоящий Telegram Web с ботом @SoftlineSupportBot.
- Кликает программа (Playwright, `scripts/video/record.mjs`). Организаторы это разрешили: продукт настоящий, запись идёт одним дублем.
- Входы выполнил человек заранее: в кабинет (`login.mjs`) и в Telegram Web (`tg_login.mjs`). Менеджер «Анна Смирнова» в соседнем браузере вошла по ссылке-приглашению администратора.
- В углу кадра — QR-коды сайта methodagent.ru и бота @SoftlineSupportBot.
- Озвучка — нейросетевой синтез речи Piper (русский голос Dmitri, локально). Субтитры совпадают с озвучкой.
- Несуществующих функций и слайдов вместо продукта нет.

## Сценарий

Слева — витрина с чатом клиента, справа — кабинет администратора.

| № | Действие | Что показывает |
|---|---|---|
| 1 | Вступление | Сайт, кабинет, QR-коды сайта и бота, каталог 136 тыс. позиций; на страницах — плашка «Демо-прототип конкурса «ИИкузница»» |
| 2 | «Не знаю, что нужно, но хотим защитить почту и файлы на 50 сотрудников» | Сценарий «не знаю»: уточняющие вопросы |
| 3 | «Коммерческая компания, Windows, Exchange, на год. А есть российский аналог?» | Варианты из каталога с ценами из фида, российские вендоры |
| 4 | Справа «Скидки»; «Сколько стоит Kaspersky Endpoint Security … на 50 ПК?» | Сценарий «знаю продукт»: агент сам называет акцию 7% из таблицы менеджера, лимит агента 5% |
| 5 | «Берём… выставьте счёт» → форма реквизитов | Реквизиты мимо модели, счёт со скидкой готов сразу |
| 6 | «Где найти закрывающие документы по оплаченному заказу?» | Ответ по базе знаний (вопрос после покупки) |
| 7 | «Позвать оператора»; справа «Команда» | Администратор и менеджеры: статусы, лимиты; обращение автоматически получила Анна Смирнова (в сети, свободна) |
| 8 | Справа «Эскалации → Все новые» | У обращения исполнитель; распределение по очереди и нагрузке, переназначение через 3 мин |
| 9 | Переход в Telegram Web, чат @SoftlineSupportBot | Эскалация с «Назначено: Анна Смирнова», резюме и кнопками; руководитель отвечает реплаем |
| 10 | Возврат на сайт | Ответ из Telegram у клиента в чате |
| 11 | Справа «Метрики» | Регламент: первый ответ агента за секунды против ~2 мин раньше |

## Как пересобрать

```bash
cd scripts/video && npm install
node login.mjs          # окно Chrome: вход в кабинет выполняет человек
node tg_login.mjs       # окно Chrome: вход в Telegram Web выполняет человек
~/.venvs/tts/bin/python make_audio.py dmitri   # озвучка нейросетевым голосом (Piper)
node record.mjs         # запись одним дублем
python3 assemble.py     # ускорение ожидания модели, звук, субтитры → out/demo.mp4
```
