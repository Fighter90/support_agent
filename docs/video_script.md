# Сценарий демонстрационного видео (до 3 минут, один дубль, без монтажа)

Требования организатора: одним фрагментом, работа продукта на данных задачи, можно ускорять ожидание ответа модели, субтитры и стрелки разрешены, склейки и показ несуществующих функций — нет.

Подготовка: два окна браузера рядом — слева https://methodagent.ru (новый диалог), справа https://methodagent.ru/manager (вход `jury`). Запись — окно браузера, голос за кадром.

| Время | Действие на экране | Что говорить |
|---|---|---|
| 0:00–0:15 | Главная: логотип Softline, цифры каталога | «Агент поддержки store.softline.ru. Работает на полном фиде магазина — 136 тысяч позиций, обновление раз в сутки, модель GigaChat на серверах в РФ.» |
| 0:15–0:55 | Сценарий 2. Ввести: «Не знаю, что нужно: хотим защитить почту и файлы на 50 сотрудников» → агент задаёт уточняющие вопросы. Ответить: «коммерческая, Windows, на год» → 2 варианта с ценами и ссылками | «Клиент не знает решения — агент выясняет требования и подбирает варианты из каталога с обоснованием. Цены — только из фида: каждая сумма проверяется кодом.» |
| 0:55–1:10 | Ввести: «А есть российский аналог?» → вариант с номером реестра | «Российский аналог — по полю реестра отечественного ПО в фиде.» |
| 1:10–1:35 | «Берём первый вариант на 50 пользователей, сделайте КП» → форма реквизитов → ООО «Ромашка», ИНН 7701234567 → кнопка PDF, открыть КП | «После согласия агент формирует КП по шаблону Софтлайна. Реквизиты идут в форму мимо модели — персональные данные в LLM не попадают.» |
| 1:35–1:50 | Новый диалог, сценарий 1: «Нужен MDaemon Standard на 10 пользователей, продление» → сверка версий | «Клиент знает продукт — агент сверяет версии и редакции и уточняет недостающее.» |
| 1:50–2:05 | «Можно скидку 15%, мы госзаказчик по 44-ФЗ?» → «Передал менеджеру» | «Скидки и тендеры агент не обещает — передаёт менеджеру с готовым резюме.» |
| 2:05–2:35 | Кабинет: «Эскалации» → резюме агента → ответить, галочка «в базу знаний» → в окне клиента появляется ответ менеджера | «Менеджер получает только сложные случаи. Его ответ уходит клиенту и пополняет базу знаний — в следующий раз агент ответит сам.» |
| 2:35–2:55 | «Диалоги» → вызовы инструментов и токены; «Метрики» → доля решённых без менеджера, стоимость запроса | «Все вопросы и ответы логируются: инструменты, токены, стоимость одного запроса — около N ₽.» |
| 2:55–3:00 | Финальный кадр | «Агент поддержки Softline: два сценария, ответы по базе знаний, КП и передача менеджеру.» |

Если модель отвечает медленно — ускорить ожидание (разрешено) и подписать «ускорено ×2».
