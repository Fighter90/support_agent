# Демонстрационное видео

Готовое видео: https://methodagent.ru/materials/demo.mp4 (2:58, субтитры в кадре и отдельным файлом `demo.srt`).

## Как оно соответствует требованиям организатора

- Продолжительность — до 3 минут.
- Один фрагмент без склеек. Ускорено ×5 только ожидание ответа модели, и в кадре в это время написано «ожидание ответа модели — в ролике ускорено».
- Работает настоящий стенд methodagent.ru на данных задачи: живой фид, база знаний, GigaChat 2 Max.
- Кликает программа (Playwright, `scripts/video/record.mjs`). Организаторы это разрешили (ответ на вопрос 13): продукт настоящий, запись идёт одним дублем.
- Вход в кабинет менеджера человек выполнил заранее в профиле записи (`login.mjs`).
- Озвучка — нейросетевой синтез речи Piper (VITS, русский голос Dmitri, локально), разговорный текст. Субтитры совпадают с озвучкой.

## Сценарий

Слева — витрина с чатом клиента, справа — кабинет менеджера.

| № | Действие | Что показывает |
|---|---|---|
| 1 | Поиск «астра линукс» в строке витрины | Подсказки из фида: 136 тыс. позиций, обновление раз в сутки |
| 2 | «Не знаю, что нужно, но хотим защитить почту и файлы на 50 сотрудников» | Сценарий 2: агент задаёт уточняющие вопросы |
| 3 | «Коммерческая компания, Windows, своя почта на Exchange, лицензия на год. А есть российский аналог?» | Варианты из каталога с ценами из фида, российские вендоры |
| 4 | «Берём Kaspersky Endpoint Security Стандартный на 50 ПК на 1 год… счёт со скидкой 5%» | Скидка до 5% по решению агента; счёт на 50 узлов |
| 5 | Форма реквизитов → «Сформировать счёт» | Реквизиты идут мимо модели, PDF по шаблону ПАО «Софтлайн» |
| 6 | «Сколько стоит MDaemon Standard на 10 пользователей, продление на год?» | Сценарий 1: сверка версий и редакций, ближайшие варианты |
| 6а | «Мы вчера оплатили счёт. Когда придёт ключ?» | Ответ по базе знаний (обязательная функция чата) |
| 7 | «Позвать оператора» | Диалог по WebSocket сразу появляется в кабинете, уведомление уходит в Telegram-бот менеджера |
| 8 | Менеджер нажимает «Взять диалог» и отвечает | Ответ мгновенно приходит клиенту, агент молчит |
| 9 | «КП и счета» → «Ссылка на оплату» | Ссылка ЮKassa (MCP, демо-режим) приходит клиенту в чат |
| 10 | Клиент оплачивает на демо-странице | Статус «Оплачено» в кабинете |
| 11 | «Telegram» → «Справка» | Подключённый Telegram менеджера; справка по работе с кабинетом |
| 12 | «Метрики» | Токены, стоимость, CSAT, эскалации по причинам |

## Как пересобрать

```bash
cd scripts/video && npm install
node login.mjs          # окно Chrome: вход в кабинет выполняет человек
~/.venvs/tts/bin/python make_audio.py dmitri   # озвучка нейросетевым голосом (Piper)
node record.mjs         # запись одним дублем
python3 assemble.py     # ускорение ожидания модели, звук, субтитры → out/demo.mp4
```
