# Описание продукта — ИИ-агент поддержки store.softline.ru

Хакатон «ИИкузница», трек «Клиентские сценарии», задача «Агент поддержки». Автор: Емельянов Сергей.
Стенд: https://methodagent.ru · кабинет менеджера: https://methodagent.ru/manager (логин жюри: `jury`, пароль — в поле формы сдачи) · репозиторий: https://github.com/Fighter90/support_agent

**Подход и архитектура.** Один LLM-агент с function calling (GigaChat 2 Max) и пятью инструментами: поиск по каталогу, версии продукта, база знаний (RAG), КП/счёт, передача менеджеру. Каталог — полный фид store.softline.ru (Mindbox YML, ~136 тыс. позиций), загружается раз в сутки в SQLite FTS5; продуктовые линейки по `group_id` дают сверку версий. База знаний — 63 статьи из справки docs.softline.com, страницы «Оплата и доставка» и FAQ по перепискам; ответы менеджеров пополняют её автоматически. FastAPI + React, Docker Compose, Caddy (HTTPS) на ВМ Timeweb Cloud в РФ.

**Принцип работы.** Клиент пишет в чат → ПДн маскируются → агент вызывает инструменты (≤ 6 шагов) → ответ проходит проверку цен по фиду (неподтверждённая сумма переписывается) → клиент получает ответ с карточками товаров. Знает продукт — сверка версий и уточнения; не знает — вопросы о задаче и 1–2 варианта с обоснованием; вопросы о покупке и после неё — ответ по базе знаний. После согласия — КП или счёт по шаблону ПАО «Софтлайн» (реквизиты — в форме, мимо модели). Скидка до 5% — сам агент (правило заказчика), больше, тендеры, «запросить цену», товар вне каталога — менеджеру с резюме. Клиент может позвать оператора кнопкой; ответ менеджера приходит в тот же чат.

**Стек и модели.** Python 3.12, FastAPI, SQLite FTS5, lxml, WeasyPrint, React + Vite, Docker, Caddy. Модели: GigaChat 2 Max (основная), YandexGPT Pro 5.1 (резерв через тот же адаптер), режим без модели — при недоступности обеих. Только российские модели и серверы в РФ: трансграничной передачи ПДн нет (152-ФЗ, ст. 12, ч. 5 ст. 18).

**Качество (51 реальное обращение из обезличенных переписок, GigaChat 2 Max):** верная маршрутизация 76,5%; тендеры передаются менеджеру в 67%; доля эскалаций 21,6% → ~78% обращений агент закрывает сам; проверка цен сработала 1 раз; ошибок 0; медиана ответа 3,7 с (сейчас менеджер отвечает через ~2 мин). Тесты: 7 модульных (pytest).

**Реализовано.** Оба сценария подбора; ответы по сведениям о продуктах и базе знаний (включая вопросы после покупки); российские аналоги; КП и счёт в PDF; скидка ≤ 5%; эскалация с 8 причинами и кнопка «Позвать оператора»; кабинет менеджера (эскалации, ответ клиенту, пополнение базы знаний, КП, журнал диалогов с токенами и стоимостью, метрики); маскирование ПДн; ежесуточное обновление каталога; защита от выдуманных цен.

**Не реализовано.** Интеграция в виджет WebIM и CRM/1С (API не предоставлены); уведомление менеджера в Telegram (сейчас — кабинет с автообновлением); обработка почты и телефонии (вне задачи по решению заказчика); резервная YandexGPT подключена в коде, но ключ на стенде не задан.

**Стоимость эксплуатации** (docs/cost.xlsx, шаблон организатора). Один запрос — 5,5 тыс. токенов, 2,96 ₽ без НДС (3,60 ₽ с НДС). При фактической нагрузке (~500 обращений за полгода, 4 сообщения в диалоге): ~62 тыс. токенов в день, модели ~1 тыс. ₽/мес, всё содержание (ВМ + сопровождение) ~12 тыс. ₽/мес; экономия времени менеджеров ~39 ч/мес (30 мин на обращение — оценка заказчика) ≈ 37 тыс. ₽/мес. При 500 обращениях в день — ~11 млн токенов в день, модели ~177 тыс. ₽/мес; удешевление — GigaChat Pro/Lite для простых вопросов. Внедрение (виджет, CRM, доработка) — ~300 тыс. ₽.

**Запуск и состав поставки.** `cp .env.example .env` → `docker compose up -d --build`; каталог загрузится из фида при старте. Состав: backend (агент, поиск, база знаний, КП, API), frontend (чат, кабинет), data/kb, eval (оценка на переписках), scripts (сборка базы знаний, расчёт стоимости), docs.

**Использованные наработки и компоненты третьих лиц.** Собственная наработка автора methodAgent (github.com/Fighter90/methodAgent, GPL-3.0): схема настроек, подход к HTTP-клиенту LLM, JWT-авторизация, многостадийный Dockerfile, каркас React + Vite — перенесены и адаптированы; остальное написано в спринте. Библиотеки: FastAPI, Uvicorn, Pydantic, httpx, lxml, PyJWT, WeasyPrint, openpyxl, React, Vite, lucide-react, Caddy, SQLite. Модели: GigaChat 2 Max, YandexGPT Pro 5.1. Ассистент разработки: Claude Code.
