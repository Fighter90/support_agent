# Описание продукта — ИИ-агент поддержки store.softline.ru

Хакатон «ИИкузница», трек «Клиентские сценарии», задача «Агент поддержки». Автор: Емельянов Сергей.

- Стенд: https://methodagent.ru
- Кабинет менеджера: https://methodagent.ru/manager (логин жюри `jury`; пароль указан в форме сдачи)
- Репозиторий: https://github.com/Fighter90/support_agent
- Материалы: https://methodagent.ru/materials/

**Подход и архитектура.** Один LLM-агент с function calling (GigaChat 2 Max) и пятью инструментами:

- `search_catalog` и `get_product_variants` — RAG по каталогу;
- `search_knowledge` — RAG по базе знаний;
- `create_quote` — КП и счёт;
- `escalate_to_manager` — передача менеджеру.

Источник товаров и цен — полный фид store.softline.ru (`Mindbox.yml.gz`, 136 040 позиций). Фид раз в сутки загружается в индекс SQLite FTS5 (BM25) с атомарной подменой. Поиск учитывает:

- точное название с сайта и ссылку на карточку (у 42% позиций фида название не уникально);
- класс ПО («офисный пакет» → МойОфис);
- русские написания брендов;
- продуктовые линейки `group_id` для сверки версий.

Наличие определяется по цене (правило заказчика). База знаний — 63 статьи (справка docs.softline.com, «Оплата и доставка», FAQ по перепискам) и ответы менеджеров. Всё работает на одной ВМ в РФ (Timeweb): FastAPI + React, WebSocket, Docker Compose, Caddy (HTTPS).

**Принцип работы.**

1. Клиент пишет в чат или ищет в строке витрины.
2. ПДн маскируются.
3. Агент вызывает инструменты (не больше 6 шагов).
4. Каждая сумма в ответе сверяется с ценами из фида.
5. Клиент получает ответ с карточками товаров.

Как агент ведёт разные обращения:

- **Клиент знает продукт:** агент сверяет версии и редакции и уточняет недостающее.
- **Клиент не знает продукт:** агент выясняет требования и предлагает 1–3 варианта с обоснованием.
- **Вопросы о покупке и после неё:** агент отвечает по базе знаний.
- **КП или счёт:** после согласия агент формирует документ по шаблону ПАО «Софтлайн». Реквизиты вводятся в форму и в модель не попадают. Оплата идёт через ЮKassa MCP; без токена магазина работает демо-режим.
- **Скидка до 5%** — решение агента. Большая скидка, отсрочка, тендеры, товары «цена по запросу» и вне каталога, низкая уверенность передаются менеджеру с резюме.
- **Живой менеджер:** клиент может позвать его кнопкой. Менеджер видит диалог в кабинете в реальном времени (WebSocket), берёт его на себя и отвечает в тот же чат.
- **Обучение:** 👍 и опрос в конце диалога пополняют примеры удачных ответов, исправления 👎 и ответы на эскалации становятся статьями базы знаний.

**Стек и модели.**

- Стек: Python 3.12, FastAPI, SQLite FTS5, lxml, WeasyPrint, WebSocket, React 19 + Vite + TypeScript, Docker, Caddy.
- Модели: GigaChat 2 Max (основная), YandexGPT Pro 5.1 (резерв через тот же адаптер).
- Используются только российские модели на серверах в РФ, трансграничной передачи ПДн нет (152-ФЗ: ст. 12, ч. 5 ст. 18).

**Качество.**

| Проверка | Объём | Результат |
|---|---|---|
| RAGAS по каталогу (эталоны из фида) | 40 вопросов | context recall 0,95 · context precision 0,88 · faithfulness 0,90 · answer relevancy 0,93 · answer correctness 0,90 · точность цен 1,00 |
| RAGAS по базе знаний | 20 вопросов | recall 0,85 · precision 0,87 · faithfulness 0,91 · relevancy 0,93 |
| Регресс на реальных обращениях из переписок | 51 обращение | маршрутизация 74,5%, ошибок 0, медиана ответа 4,1 с (сейчас ответ человека ~2 мин) |
| Сквозной тест реалтайма, кабинета и оплаты | 22 проверки | 22/22 |

**Реализовано.**

- Оба сценария подбора и сверка версий.
- Ответы по каталогу и базе знаний, включая вопросы после покупки; российские аналоги.
- КП и счёт в PDF, скидка до 5%, онлайн-оплата (ЮKassa MCP, демо-режим).
- Кнопка «Позвать оператора», 8 причин эскалации.
- Кабинет менеджера:
  - живой чат на WebSocket: перехват диалога, «печатает…», быстрые ответы;
  - эскалации;
  - журнал диалогов с инструментами, токенами и стоимостью;
  - КП и счета, ссылка на оплату;
  - отзывы с исправлением в базу знаний;
  - метрики и CSAT.
- Опрос полезности и обучение на отзывах.
- Поиск по каталогу на витрине.
- Маскирование ПДн, ежесуточное обновление каталога, защита от выдуманных цен.

**Не реализовано.**

- Встраивание в виджет WebIM и интеграция с CRM и 1С: API не предоставлены.
- Уведомления менеджеру в Telegram: вместо них кабинет в реальном времени.
- Почта и телефония: вне задачи по решению заказчика.
- Реальный магазин ЮKassa: нужен токен заказчика, на стенде работает демо-режим.
- YandexGPT подключён в коде, но ключ на стенде не задан.

**Стоимость эксплуатации** (`docs/cost.xlsx`, шаблон организатора).

- Один запрос — около 5,4 тыс. токенов: 3,49 ₽ с НДС, 2,86 ₽ без НДС.
- Фактическая нагрузка (~500 обращений за полгода): около 62 тыс. токенов в день. Модель стоит ~1 тыс. ₽/мес, всё содержание — ~12 тыс. ₽/мес. Экономия времени менеджеров (30 мин на обращение) — ≈37 тыс. ₽/мес.
- Сценарий роста (500 обращений в день): модель ~177 тыс. ₽/мес.

**Запуск и состав поставки.**

1. `cp .env.example .env` и указать ключ GigaChat и пароли.
2. `docker compose up -d --build`: каталог загрузится из фида при старте.

Состав поставки:

| Каталог | Содержимое |
|---|---|
| `backend/` | Агент, поиск, база знаний, КП и счета, оплата, WebSocket, API |
| `frontend/` | Витрина с чатом, кабинет менеджера, демо-страница оплаты |
| `data/kb/` | Статьи базы знаний |
| `eval/` | Регресс, RAGAS по каталогу и базе знаний |
| `scripts/` | Сборка базы знаний, расчёт стоимости, руководства, e2e-тест, видео |
| `docs/` | Решение, руководства пользователя, менеджера и администратора (DOCX/PDF), расчёт |

**Использованные наработки и компоненты третьих лиц.**

- **Собственная наработка автора — methodAgent** (github.com/Fighter90/methodAgent, GPL-3.0). Из неё перенесены и адаптированы схема настроек, HTTP-клиент LLM, JWT-авторизация, многостадийный Dockerfile и каркас React + Vite. Остальное написано в спринте.
- **Библиотеки:** FastAPI, Uvicorn, Pydantic, httpx, lxml, PyJWT, WeasyPrint, openpyxl, React, Vite, lucide-react, Caddy, SQLite, Playwright (запись демо).
- **Модели и сервисы:** GigaChat 2 Max, YandexGPT Pro 5.1, ЮKassa MCP. Озвучка видео — нейросетевой синтез речи Piper (голос Dmitri).
